# SchemDepot

A lightweight collaborative asset registry built on top of FastAsyncWorldEdit (FAWE).

Turn a FAWE clipboard into a reusable server asset, track who registered it, browse the
shared asset library, and paste any asset with one short command.

## Status

Work in progress (skeleton). See `docs/SchemDepot_DESIGN.md` for the full technical
specification and implementation roadmap.

## Requirements

- Paper 26.1.2+ (or Purpur equivalent)
- FastAsyncWorldEdit 2.15.3+
- Java 25

Full command reference, permissions, and install steps will be added in Phase 8 once the
plugin reaches feature completeness (see `docs/SchemDepot_DESIGN.md` SS29 Phase 8).
